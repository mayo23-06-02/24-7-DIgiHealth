Headline finding

11 of the 17 defects sat in code previously marked “complete”. That prior status was assigned by reading the code rather than running it. One endpoint returned 404 for every real account; two dashboards silently substituted hardcoded numbers for live data; an audit log discarded every action performed by an entire class of administrator. None of these are visible to inspection — each one returns a success status while doing the wrong thing.
